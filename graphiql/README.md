saf graphiql
================

All kode i denne modulen er kopiert fra dependency:

```
<dependency>
    <groupId>com.graphql-java</groupId>
    <artifactId>graphql-spring-boot-starter</artifactId>
    <version>5.0.2</version>
</dependency>
```

### Endret
`graphiql.html` er endret til å ikke hente `subscriptions-fetcher-client-0.0.2.js` og `subscriptions-transport-ws-0.8.3.js` fra nettet.
